# **Spatial Data and GPS Projection Concepts**

* Three spatial data types covered: point (lat-long), line (array of lat-longs), polygon (line where start \= end point)  
  * Bus GPS data is point data, subject to GPS uncertainty (circle of error)  
  * Points will not land precisely on road segments due to sensor error (3-10 meter range)  
* Core task: project GPS points onto road segments at 90 degrees to determine bus position at each timestamp  
* After projection: distribute time across readings and detect dwell time at stops  
* Model goal: learn travel time between stops from this processed data
