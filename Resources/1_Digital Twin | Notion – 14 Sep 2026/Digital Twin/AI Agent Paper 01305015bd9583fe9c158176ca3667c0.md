### **Topic 1 (Lead: Eunjoo & Jiho)**

**Title**: 
***From Intent Chains to LangGraph + MCP: Orchestrating AI Agent Architectures for Urban Mobility Simulation Control***

or 

**Designing AI Architectures for Urban Mobility Simulation: A Comparative Study of Control Frameworks**

**Motivation:**

This research investigates the architectural evolution of AI agent systems for urban traffic simulation control—from LangChain-based intent chains to LangGraph with Model Context Protocol and multi-agent orchestration—with the ultimate goal of identifying the most effective and scalable framework for iterative policy experimentation.

**Focus**:

- Transition from LangChain-based Intent-Chain structure to a more advanced architecture using **LangGraph + MCP (Model Context Protocol)**.
- Evaluate structural, functional, and performance advantages in real-world urban simulation environments (e.g., DTUMOS).

**Key Components**:

- **Modular Simulation Workflow using LangGraph**
    - Define each process (policy generation, validation, execution, analysis) as discrete nodes
    - Enable iterative loops, conditional branches, and explicit state transitions
    - Facilitate better debugging, traceability, and policy feedback loops
- **Integration of MCP (Model Context Protocol) with DTUMOS**
    - Specify simulation tool inputs and outputs in a machine-readable schema
    - Prevent misuse by enforcing parameter constraints and expected behaviors
    - Allow AI agents to invoke DTUMOS more reliably and safely
- **Comparative Evaluation with Legacy LangChain Architecture**
    - Reimplement equivalent workflows using LangChain’s intent-chain structure
    - Evaluate and compare both architectures in terms of:
        - Workflow flexibility and modularity
        - Agent interpretability and tool alignment
        - Reusability and scalability
        - Robustness under complex or iterative scenarios
- **Ultimate Goal: Identifying the Optimal Agent Architecture**
    - Determine which design best supports adaptive, interpretable, and robust simulation control
    - Provide architectural guidelines for future AI agent-based urban simulation systems

### **Topic 2 (Lead: Madu and Sehra)**

**Title**:

***Explainable and Scenario-Aware AI Agents for Urban Policy Evaluation***

**Motivation:**

This research focuses on improving transparency and diversity in AI-assisted urban policy simulation. It proposes AI agents that not only generate diverse policy scenarios but also explain simulation outcomes in natural language—bridging the gap between simulation outputs and human understanding.

**Focus**:

- Automatically generate and test diverse mobility policy scenarios
- Translate simulation results into interpretable summaries for decision-makers

**Key Components**:

- **Scenario Generator Agent**
    - Prompted to generate multiple policy variants (e.g., congestion pricing, transit expansion)
    - Convert high-level ideas into structured simulation parameters
- **Simulation Workflow Compatibility**
    - Reuse LangGraph + MCP infrastructure for execution
    - Batch scenario testing via automated loops
- **Result Explanation Agent**
    - Analyze output logs (e.g., wait time, failure rate, emissions)
    - Produce natural language summaries of trade-offs and policy effects
- **Evaluation Framework**
    - Human-in-the-loop assessments: do the summaries reflect simulation behavior accurately?
    - Coverage and variety of generated scenarios
- **Simulation Performance Optimization**
    - Implement parallel or multithreaded scenario execution to accelerate batch testing
    - Apply lightweight configuration modes (e.g., reduced visual output, fast-forward simulation ticks)
    - Optimize DTUMOS internals for scalable scenario evaluation, including code-level enhancements for simulation loop efficiency and memory management

### **Topic 3 (Lead: Mubarak - Future)**

**Title**:

***Data-Adaptive Simulation Agents Using Real-Time Traffic and ETA Models***

**Motivation:**

This research explores how real-time urban data—such as traffic flow and estimated travel time (ETA) models—can be integrated into simulation workflows to dynamically optimize simulation parameters. The goal is to reduce the gap between simulated and observed behaviors, enabling more realistic and responsive urban mobility simulations.

**Focus**:

- Leverage real-time traffic conditions to adjust simulation parameters (e.g., vehicle demand, signal timings)
- Link adaptive agents with evolving ETA models to improve data realism
- Automate the tuning of simulation configurations in DTUMOS

**Key Components**:

- **Real-Time Data Integration**
    - Ingest live or historical traffic speed, density, and congestion data
    - Extract input features for ETA prediction and simulation adjustment
- **ETA Model Integration**
    - Use ETA model outputs to refine trip generation and routing assumptions
    - Co-adapt simulation outputs and ETA estimates over time
- **Parameter Optimization Agent**
    - Modify simulation parameters dynamically (e.g., fleet size, dispatch interval)
    - Evaluate the effect of parameter tuning on simulation realism and stability
- **Evaluation Framework**
    - Compare static vs adaptive configurations
    - Metrics: prediction accuracy, convergence speed, deviation from real-world data

### **Topic 4 (Lead: Minsu - Future)**

**Title**:

***Multi-Stakeholder Policy Coordination in Multimodal Mobility Systems Using Agent-Based Simulation***

**Motivation:**

Urban mobility decisions involve competing interests among city authorities, service operators, and users. This study extends the DTUMOS simulation framework to include multi-agent negotiation, allowing different stakeholders to debate, propose, and refine mobility policies within a simulated decision process.

- [https://microsoft.ai/new/the-path-to-medical-superintelligence/](https://microsoft.ai/new/the-path-to-medical-superintelligence/)

**Focus**:

- Introduce stakeholder-specific agent roles with distinct goals and constraints
- Coordinate through negotiation to resolve conflicting preferences in policy design

**Key Components**:

- **Stakeholder Agent Modeling**
    - Define agents for city planners, private operators, and commuters
    - Assign constraints, utilities, and negotiation behaviors to each agent
- **Multimodal Mobility Simulation (DTUMOS-based)**
    - Simulate the outcome of proposed policies under conflicting agent preferences
    - Include shared mobility, paratransit, and demand-responsive services
- **Negotiation and Conflict Resolution Framework**
    - Implement structured dialogue or decision rules (e.g., voting, scoring, argumentation)
    - Explore both rule-based and LLM-based coordination strategies
- **Evaluation**
    - Measure policy convergence, fairness, and system efficiency
    - Compare individual-policy vs negotiated-policy outcomes
